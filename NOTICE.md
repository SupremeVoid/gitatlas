## Bundled font

This project embeds **Roboto Mono** (`assets/RobotoMono.ttf`) directly into the
binary via `include_bytes!`. Roboto Mono is © Google and is distributed under
the **Apache License, Version 2.0**. A copy of that license is provided in
`assets/Apache-2.0.txt`. No modifications have been made to the font file.

## Runtime dependency

`gitatlas` shells out to the system-installed **git** and **ffmpeg** binaries at
runtime; it does not bundle or link them. They are used under their own
licenses (GPLv2 and LGPL/GPL respectively).

## Rust crate dependencies

The binary statically links a tree of Rust crates, each under its own permissive
license (MIT, Apache-2.0, ISC, BSD-2/3-Clause, Zlib, Unicode-3.0 and
CDLA-Permissive-2.0). The full license text of every dependency is reproduced in
[`THIRD-PARTY-LICENSES.md`](THIRD-PARTY-LICENSES.md), which ships alongside the
binary in each release archive.

That file is generated by [`cargo about`](https://github.com/EmbarkStudios/cargo-about)
from `about.toml` / `about.hbs`. Regenerate it after changing dependencies:

```bash
cargo install cargo-about
cargo about generate about.hbs -o THIRD-PARTY-LICENSES.md
```
